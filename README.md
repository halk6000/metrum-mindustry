# Metrum Industry Drones

[![Build Status](https://github.com/AkinoxPl/Metrum/workflows/Build/badge.svg)](https://github.com/AkinoxPl/Metrum/actions)

This is a Mindustry mod that adds industry, drones, fuel logistics and particle physics for a new planet.

## Features

- **Industry**: New factories, production chains, and resource processing
- **Drones**: Various drone types with different capabilities and upgrades
- **Fuel Logistics**: Advanced fuel management system with tanks, refueling, and distribution
- **Particle Physics**: Physics-based effects and interactions
- **New Planet**: Ferrox - a new planet to explore with unique resources and challenges

## Building

To build this mod, run:

```bash
gradlew jar
```

The resulting `Metrum.jar` file will be placed in the `build/libs` directory.

## Installation

1. Place the built `Metrum.jar` file into your Mindustry mods folder (`saves/mods`)
2. Launch Mindustry and enable the mod in the settings
3. Start a new game or load an existing save with the mod enabled

## Content

### Units
- **Mono-Met** drones: Basic mining and construction units
- **Modular Drones**: Upgradeable drone designs with different hulls
- **Specialized Units**: Units with specific roles (combat, support, etc.)

### Blocks
- **Factories**: Production facilities for various resources
- **Fuel Systems**: Tanks, pumps, and distribution networks
- **Power Generation**: New power sources including reactors
- **Storage**: Advanced storage solutions

### Items
- **Iron**: Basic resource for construction
- **Advanced Materials**: Various materials for upgrades and production

### Liquids
- **Fuel**: Used for drone operations and vehicles
- **Coolant**: Required for high-temperature processes

## Compatibility

This mod is compatible with Mindustry version 160 and above.
